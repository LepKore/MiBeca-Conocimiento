# Enlaces web

Registro de **toda fuente de internet** que se consultó y de la que se extrajo conocimiento
para este vault. La regla está en [[Cómo mantener este vault]].

**Para qué:** que nadie tenga que volver a buscar lo mismo, y que se sepa de dónde salió un
dato cuando el enlace se caiga o cambie.

## Cómo se añade una fila

1. Se añade **una fila por enlace**, con la fecha en que se consultó.
2. La columna *Nota* apunta a la nota del vault donde se usó el contenido. Si no hay nota, el
   dato no debería estar en el vault.
3. Si el enlace muere, **no se borra la fila**: se marca `caído` y se pone el espejo o la copia
   en `docs/` junto al resto de fuentes.

> [!important] Ficheros, no solo enlaces
> Si la fuente es un **PDF, DOCX, XLSX, CSV, PPTX o similar**, el archivo se guarda en esta
> misma carpeta `docs/` y se registra abajo igual que un enlace. Ver [[Cómo mantener este vault]].
